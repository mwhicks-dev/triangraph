# triangraph

TrianGraph is a C++ solver for the problem of creating graph triangulations from a point set that satisfy certain solution criteria. 

The structure of this repository is borrowed from some combination of [grapph](https://github.com/mwhicks-dev/grapph) and [SPlat](https://github.com/mwhicks-dev/SPlat), my best and my most fun C++ projects respectively to date. The branch-and-bound implementation is inspired and modeled after my undergraduate research mentor, [Dr. Matt Stallmann](https://mfms.wordpress.ncsu.edu/), who inspired my interest in experimental algorithms and computer science research.
